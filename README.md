# Instrucciones

## Requerimeintos
- Gradle:   8.10.2+
- OpenJDK:  17.0.13_p11+
- Lombok:   v1.18.36

## Validaciones
Antes de inciar, valida que tu IDE tiene instalado el complemento para soportar Lombok, en caso contrario descargar el instalador desde la pagina oficial de [Lombok](https://projectlombok.org/) asi como las demas dependencias.

## Ejecución
#### Limpiar y construir 
```bash
~$gradle clean build
```

#### Ejecutar
```bash
~$gradle bootRun
```
